# Independent review of original stress controls

Verdict: clean for the documented 22 original-CNF controls. I read `controls.py`, `test_controls.py` and `THEOREM.md` independently of the weighted solvers. No production changes were needed. The existing three tests passed in 0.228 seconds in the review run; `independent_review.py` persists additional source-bound checks below.

For each cubic parity instance, the producer supplies one variable per original graph edge and all four clauses forbidding the wrong assignments at every degree-three vertex. Its product-order enumeration and the checker's integer-word enumeration produce the same four clauses. The checker compares full sorted clause lists, retaining multiplicity. It also checks simple endpoints, degree, connectivity, an explicit spanning tree, binary rank and augmented consistency. Connected incidence rank is exactly V−1, and its only row dependency is the sum of all vertex rows. Consequently the exact counts are zero at odd total charge and `2^(E−V+1)` at even charge. This is an original-CNF count, not a count of a relaxed native-factor replacement.

All eight grouped/shuffled pairs have identical graph edges, charges and complete clause multisets. Order changes can affect a chosen decomposition's work without changing the original function. Solver outcomes for those two orders must remain separate, including UNKNOWN results. This audit does not certify generic graph expansion or a lower bound for all algorithms.

For pigeonhole instances, each pigeon row is nonempty while each hole column contains at most one true entry. With p=h the total number of true entries is forced to equal h, so every row and column has exactly one and the model count is h!. With p=h+1 the row lower bound exceeds the column upper bound and the count is zero. No row-at-most-one constraints were silently assumed before this equality argument. The verifier reconstructs the full clause list. The code intentionally supplies only these two p ranges; h! is not asserted for general p<h.

The saved audit replays all 22 source controls and separately deletes every original clause occurrence. All 2,611 omissions are rejected. It checks all eight grouped/shuffled pairs. It independently enumerates the possible owner (or empty state) of each hole for all six pigeonhole controls and checks that every pigeon occurs; these counts agree with the structural formula. Finally it directly evaluates original CNF truth tables for 18 small formulas, independently of the weighted solvers.

Reproduce with `python independent_review.py`. `INDEPENDENT_REVIEW.json` records exact counts, original control names, source hashes for the producer/tests/theorem and this review script/document, and verifies those files were unchanged throughout. No benchmark result file is used to derive an expected count. The control checker uses Python assertions and the documented run uses ordinary Python execution; this is a finite experiment validator, not an assertion-disabled untrusted-input service.
