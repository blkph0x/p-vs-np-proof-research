# Independent affine-weight signature review

A separate aggregation implementation reproduces one nonzero Walsh signature entry per column for the k=7, 8 and 9 explicit families. An exhaustive eight-assignment control confirms equality under duplicate affine rows and rejects an offset mismatch. Signed weights are accepted as an adversarial control, so the row-count lower bound also covers nonnegative affine encodings. This remains a full-objective theorem; nonlinear and threshold-only encodings are outside scope.
