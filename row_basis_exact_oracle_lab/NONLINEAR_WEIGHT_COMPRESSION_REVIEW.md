# Independent nonlinear compression review

A separate implementation exhaustively checks the binary-digit identity on 32 assignments and samples seven assignments from each k=7, 8 and 9 explicit family. The exact objective is recovered with 14, 16 and 18 nonlinear digit rows. A one-row threshold control is also checked. This is a scope boundary, not a solver or P-versus-NP result: row evaluation still contains the underlying source-form computation.
