# Independent explicit-code review

The deterministic trace/Reed--Solomon construction is replayed at k=7, 8 and 9. A second field/trace/column implementation independently reproduces the hashes and sampled transformed statistics. Field irreducibility, column distinctness and distance bounds all agree. The forced state lower bounds are 2^14, 2^32 and 2^54. An exhaustive enumeration of all 16,383 nonzero degree-one messages at k=7 also attains the predicted minimum distance 8,128. This is a lower bound for one representation route, not a P-versus-NP proof.
