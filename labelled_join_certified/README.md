# Certified labelled graph optimization

This follow-up implements the previously reviewed labelled-join design. It
adds a proved deterministic algorithm for supplied graphic matrices with a
small number of arbitrary parity rows, while retaining the exponential
parameter costs and testing the limits of that representation.

**P versus NP remains unresolved.** The class-specific solving theorem does
not provide a universal representation theorem. [COVERAGE_AUDIT.md](COVERAGE_AUDIT.md)
proves that two natural universal representations in this format are false.

Start with [REPORT.md](REPORT.md) for the implemented result, 37 core tests
plus 14 follow-up tests, 49 saved and independently replayed benchmark cases,
and the remaining gap.

## Implementation

- `labelled_tables.py`: lifted shortest paths, disconnected Eulerian label
  closure, and independent distance/predecessor/Bellman/reachability checks.
  The verifier never calls shortest-path search.
- `labelled_tjoin.py`: arbitrary-terminal subset DP and complete edge-pin
  nonemptiness reduction. All DP minima and every required pin are checked.
- `code_lift_solver.py`: a supplied row form is checked against the original
  binary equations, objective weights, target syndrome, and nonzero request.
- `sparse_lift_normal_form.py`: polynomial graph contraction converts a supplied
  sparse-U decomposition H=B+UV to the checked graph-plus-label row form.
- `small_terminal_perturbation.py`: deterministic branch enumeration for a
  supplied same-coordinate perturbation H=B+UV. Each label branch is replayed
  by the certified labelled T-join solver, including disconnected cycles and
  the nonempty zero branch.

The implementation uses nonnegative **integer** costs. Rational costs have a
separate scaling argument in the theory review, but the public API deliberately
accepts integers only. All modules use Python's standard library.

## Reproduce

From this folder:

```powershell
python run_checks.py
python run_lift_experiments.py
```

The first command saves the test transcript, source hashes and summary. The
second saves exact original inputs, all requested objectives and targets,
source hashes, finite reference checks, full certificates and timings. Original
matrix coordinates are preserved throughout; loops and parallel edges remain
separate selectable coordinates.

Caps return `UNKNOWN`. A verified upper-bound support from a partial pin pass
is not an exact optimum. A certificate checker that runs out of resources also
returns `UNKNOWN`, separately from rejection of invalid evidence. Search work,
verification arcs, DP states/transitions and pin counts have explicit limits.

The [theory review](THEORY_REVIEW.md) records independent proof and implementation
audits, including a found-and-fixed resource-accounting bug. The
[coverage audit](COVERAGE_AUDIT.md) distinguishes supplied representations,
discovery, affine targets, original-coordinate objective preservation, linear
auxiliaries and unrestricted P-versus-NP claims. No novelty is claimed.

The small-terminal extension is documented in
[PERTURBATION_SMALL_TERMINAL_THEOREM.md](PERTURBATION_SMALL_TERMINAL_THEOREM.md).
Its saved controls are generated by `python run_small_terminal_experiments.py`:
160 random tiny perturbations agree with exhaustive original-assignment minima,
alongside explicit inconsistent-branch, wrong-label-path and cap controls.
The 2^p branch enumeration is an explicit parameter cost; it does not provide
a universal polynomial algorithm. Replay them with
`python verify_small_terminal_results.py`. The same artifact also includes 80
random end-to-end original-matrix adapter cases.

The dense-U coverage count is recorded separately in
[PERTURBATION_COVERAGE_THEOREM.md](PERTURBATION_COVERAGE_THEOREM.md) and
[PERTURBATION_COVERAGE_RESULTS.json](PERTURBATION_COVERAGE_RESULTS.json).
It allows arbitrary U and V and still excludes universal O(log n) labels for
this same-coordinate representation language by exact integer comparison. The
saved controls also compute the largest excluded label budgets 9, 24 and 55
at n=128, 256 and 512 after allowing every displayed row count.
