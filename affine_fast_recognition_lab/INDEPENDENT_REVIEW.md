# Independent review of fast negative recognition

The fast wrapper was read as a separate layer over the frozen complete
one-piece recognizer. A probe can return only a source-bound obstruction or an
inconclusive result; a local cap never becomes an impossibility certificate.
Every sampled value is recomputed from every original explicit piece, and the
verification path derives the same input binding independently.

The review script replays all 494 saved explicit-sum requests. For every
request with at most three coordinates it builds a separate direct truth-table
oracle: it sums the original rational pieces, checks affine support closure,
and recovers the degree-at-most-two sign function from Boolean finite
differences. It rejects any fast false acceptance or false rejection. Larger
requests are checked for certificate validity and for no UNSUPPORTED result on
a saved EXACT claim. A sample of binding mutations is rejected by fresh
verification. The saved JSON records source hashes, counts and total work.

This is an implementation review of a bounded representation probe. It does
not establish a minimum-piece algorithm, a polynomial bound for the full SAT
solver, or a P-versus-NP result.
