# Tseitin expander campaign

This lab records exact odd-charge Tseitin contradictions on four small
connected cubic graphs. It stores the CNF, parity certificate, proof-producing
CDCL result, and a second replay that rebuilds both the encoding and the
resolution trace.

The experiment is a finite solver and proof-complexity control. It does not
claim a new asymptotic lower bound or a solution to P versus NP. See
[`THEOREM.md`](THEOREM.md), [`REPORT.md`](REPORT.md), and the cited
Ben-Sasson--Wigderson paper in the repository citation ledger.
