# Formal finite model for the pinned RM(2,5) level-eight relaxation

This note gives the mathematical object that the level-eight producer and its
independent checker implement. It is deliberately separate from the symmetry
quotient code, so a reader can audit the specification before reading the
enumeration.

## Code and pin

Identify the 32 coordinates with the points of `F_2^5`, numbered `0,...,31`.
Let `C = RM(2,5)` be the binary evaluation code generated by the Boolean
monomials of degree at most two. Thus `dim(C)=1+5+10=16`. The pinned code is

```text
C_0 = { c in C : c_0 = 1 }.
```

The producer enumerates `C_0` exactly from those 16 evaluation rows; it does
not load a list of codewords from the certificate. The Reed--Muller parameter
identities used here are sourced to [Reed's original paper](https://doi.org/10.1109/TIT.1954.1057465).

## Local tables

For every nonempty coordinate scope `S` with `|S| <= 8`, define the exact
support

```text
A_S = { c restricted to S : c in C_0 }.
```

The unquotiented LP has one nonnegative variable `lambda[S,a]` for every
`a in A_S`. These tables are local objects: the definition does **not** assume
that all tables are marginals of one probability distribution on `C_0`.

For each scope, impose normalization

```text
sum_(a in A_S) lambda[S,a] = 1.
```

For every parent scope `P`, every nonempty proper child `Q subset P`, and every
`b in A_Q`, impose the exact containment equation

```text
sum_(a in A_P : a restricted to Q = b) lambda[P,a] = lambda[Q,b].
```

All coefficients and right-hand sides are integers. The certificate code uses
the reduced (free-coordinate) objective

```text
F = minimize  sum_(i=1,...,31) lambda[{i}, 1].
```

The corresponding total pinned-codeword weight is `W = 1 + F`, because the
pin contributes one. Every pinned codeword gives an integral feasible point.
For RM(2,5), the minimum integral values are `F=7` and `W=8`; the two numbers
must not be compared across conventions. The certificate claim below concerns
the rational relaxation itself and does not silently identify all integral
local-table assignments with global codewords.

## Quotient representation

The implementation does not materialize every unquotiented variable. The group
`G = GL(5,2)` acts on `F_2^5` and fixes coordinate zero. It preserves `C_0`,
all supports, all containment equations, and the objective. Averaging any
feasible point over `G` gives an invariant feasible point with the same
objective, so restricting to invariant tables preserves the optimum.

The saved quotient enumerates scope orbits, then atom orbits under each scope
stabilizer, and finally equation orbits. The current finite instance has
`2,174` variable orbits, `27,926` quotient rows, and `214,059` nonzero matrix
entries. The proof that this quotient is equivalent to the declared LP is in
[`REED_MULLER_QUOTIENT_EQUIVALENCE.md`](REED_MULLER_QUOTIENT_EQUIVALENCE.md).

The exact full-model result is a rational primal certificate with reduced
objective `F=31/5`, together with an independently checked affine-overlap
lower bound of `F=31/5`. In total-weight language the same certificate is
`W=36/5`. Its conclusion is therefore the finite equality

```text
opt_F(L_full, RM(2,5), level 8) = 31/5,
opt_W(L_full, RM(2,5), level 8) = 36/5.
```

not a statement about an unbounded hierarchy or arbitrary SAT.

## Trust boundary

The producer and reviewer independently rebuild the code support, objective,
scope orbit data, stabilizer closures, quotient matrix, primal equalities, and
dual reduced costs. This is a strong replayable software check. It is not a
formal proof-assistant development: the quotient theorem above is a written
mathematical argument, and the finite enumeration remains an executable
implementation subject to ordinary program-audit assumptions. The complete
dependency chain is recorded in [`TRUST_CHAIN.md`](TRUST_CHAIN.md).
