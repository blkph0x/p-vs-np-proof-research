# Independent full level-eight replay

The pure-standard-library replay rebuilt the pinned RM(2,5) support, all 92 scope orbits, stabilizer closures, all 2,174 variable orbits, all 27,926 row orbits, the 214,059-nonzero quotient matrix, and every rational primal equality. It also rejected a wrong support atom, a perturbed primal mass, a mutated stored matrix row, and a mutated stored objective vector by invoking the complete replay on each corrupted certificate. The exact non-pin value is 31/5 (total 36/5); the lower bound is inherited from the affine-overlap submodel. The checker independently rebuilds the singleton objective and reruns the complete replay against mutated matrix and objective certificates.
