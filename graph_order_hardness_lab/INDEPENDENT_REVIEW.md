# Independent vertex-separation review

A separate set-based implementation reconstructed every saved boundary and recomputed the subset-DP optimum. The star control has width 7 under the leaf-first order and width 1 under the optimal center-first order; path, cycle and complete-graph controls agree. The associated monotone 2-CNF clauses are all satisfiable by the all-ones assignment, so the layout cost is separate from SAT difficulty. The K4,2 greedy control has width 4 while an exact order has width 2.
